# Spot 変更履歴

著者: **Manus AI**  
対象: [https://spotatlas-jettiem7.manus.space/](https://spotatlas-jettiem7.manus.space/)

この履歴は、SaaS ランディングに見えていたスポット地図を、静かな紙のアトラスへ直したあとの公開面を記録します。元になった公開例は `Spot_info` タイトルの旧ホストです。改定後の公開ホストは `spotatlas-jettiem7` です。既存機能を落とす次の改定は、実装前に確認し、改定後はソースとこのドキュメント一式を再び ZIP にできる状態へ戻します。[1] [2]

## 2026-09-22 — 公開面の確定（この一式）

公開 HTML、`spots.list`、サンドボックスブラウザで次を確認しました。Google サイトへの埋め込み URL と WebDev checkpoint は、このセッションでは未記録です。

確認した公開面:

- `lang="ja"`、`<title>Spot</title>`、OG タイトルも Spot
- フォントは Shippori Mincho（見出し）と IBM Plex Sans JP（本文）
- 正直な件数「公開 3件 · 誰でも残せる」
- ナビ三語: 見つける · 残す · つなぐ
- 地図: Street View / 地図種別 / 全画面オフ、ズームのみ
- 東京ビュー、フォード博物館は一覧末尾で **地図の外**
- `/my` は未ログイン時に Manus サインインへ送る
- 公開スポット 3 件。すべて `ownerUserId: null`

ドキュメント一式（本 ZIP）を、公開 URI・利用ガイド・変更履歴が揃った状態で渡せるように整理しました。ソースツリーはこのセッションに WebDev プロジェクトが無いため含めていません。

## 改定で残したもの

紙色、インク、コーラル、見出し「ここ、いいよ」、三語ナビ、ログイン無しで残せる姿勢は残しました。東京の実データ（上野公園、錦糸公園）と、画角外のフォード博物館も、製品のデータとして残しています。サンプル地点を新しく作ってはいません。[3]

## 改定で切ったもの

信用を盛る指標カード（`AK+`、`FREE`、重複 CTA）は出していません。デバイス風のガラスのヒーローは、地図をキャンバスにする構成に置き換えました。デフォルトの Google マップクロムのうち Street View、地図種別、全画面はオフです。ピル型の装飾と、3 件すべて「その他」という分類は使いません。`lang="en"` のまま日本語アトラスを出すこと、`Spot_info` / `Spot info` の分裂、フッターで Manus がブランドと競合するコピーは止めています。画面右下の "Made with Manus" はホスト側のバッジで、プロダクト名ではありません。[3]

## データについて

公開 3 件のひとことは、公開 API の文言をそのまま記録しています。上野公園は「都会の中の自然界隈」です。OCR 風の置換（自然界隊 など）は入れていません。添付ファイルは公開リストに無く、移行履歴上も空です。カスタムカテゴリー「公園」「博物館」はデータ由来です。ビルトイン例（風光明媚 / 娯楽 / 宿泊 / その他）を、この 3 件に後付けしてはいません。[4]

## 所有者操作

作成はゲストでも公開されます。サーバは `ownerUserId: ctx.user?.id ?? null` を刻みます。`spots.mine` / `update` / `delete` はログイン必須で、本人の行にだけ効きます。`/my` の空状態はアトラスへ戻すだけで、偽の行を置きません。公開一覧にコーラルの編集ボタンは増えません。[3]

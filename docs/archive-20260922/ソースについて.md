著者: **Manus AI**

ドキュメント一式にはソースを含めます。改定後はソースとドキュメントを同じ ZIP で渡せる状態にします。[1]

この一式の `source/` は、公開ホスト `spotatlas-jettiem7` の本番バンドルから復元した製品差分です。WebDev の git checkpoint そのものではありません。セッションにプロジェクトが無いため、`manus-webdev://` の識別子は空欄のままです。

復元の根拠は次です。

- HTML: `lang="ja"`、`<title>Spot</title>`、フォントリンク
- JS: `data-loc` が `client/src/pages/Home.tsx`、`MySpots.tsx`、`Map.tsx`、`App.tsx` を指す
- 公開 RPC: `spots.list` / `create` / `mine` / `update` / `delete`
- CSS `:root` の紙 `#f3eee4`、カード `#fbf7ee`、インク `#1c2430`、コーラル `#de6848`

元タスク側で checkpoint が取れたら、`source/` をその内容で差し替え、`公開URL.md` の Checkpoint 欄を埋めてください。

# Spot 利用ガイド

著者: **Manus AI**  
対象公開面: [https://spotatlas-jettiem7.manus.space/](https://spotatlas-jettiem7.manus.space/)

このガイドは、公開中の Spot を訪れる人と、自分の登録を後から直す人のための操作説明です。画面の文言は 2026-09-22 の日本語表示を正とします。右上の **JA | EN** で英語に切り替えられます。ブランド名はどちらの言語でも **Spot** です。

## 最初に見えるもの

ページを開くと、紙のアトラスの上に短い見出しがあります。

> あなたの「ここ、いいよ」を地図に残そう。

ナビは三語だけです。**見つける** は地図帳へ、**残す** は登録フォームを開き、**つなぐ** は「見つける人と、残す人が、同じ地図を育てる」の説明へ進みます。コーラル（`#de6848`）は **登録**、ピン、地図検索の送信に使い、他のピルや補助ボタンには広げません。

ヒーロー下の数字は実件数です。いまは次の一文です。

> 公開 3件 · 誰でも残せる

左側の黒いボタン **地図帳をひらく** は `#atlas` へスクロールします。右側のアウトライン **新しいスポットを残す** は、地図クリックと同じ登録フォームを開きます。ログインは残すために必須ではありません。ログインは、あとから自分の分だけを直すときに使います。[1]

## 見つける

地図帳はページの本体です。Google マップの Street View、地図種別、全画面は出していません。ズームだけ残しています。地図は東京を先に見せます。

地図上の検索欄に地名や施設名を入れ、コーラルの **地図で探す** を押すと、Geocoder が日本優先（`region: jp`）で位置を探して地図を寄せます。見つからないときは「見つかりませんでした。」と出ます。

右の **スポット一覧** は、公開された場所の全文検索とカテゴリー絞り込みです。カテゴリーボタンはデータから作られます。いまは **すべて / 公園 / 博物館** です。一覧は東京圏を先に並べ、圏外は末尾に **地図の外** を付けます。フォード博物館はミシガンにあり、ピンは東京の画角には入りませんが、一覧から消してはいません。

地図上のコーラルピンを押すと、その場所へパンします。一覧の行を押しても同じ場所を選べます。公開件数の横に **2 範囲内** と出るのは、東京の画角に実際に載っている件数です。信頼のために件数を水増ししていません。[1]

## 残す

ログインしなくても残せます。地図上の空いている地点をクリックすると、緯度経度が入り、フォーム **新しいスポットを残す** が開きます。ナビの **残す** やヒーローの **新しいスポットを残す** からも同じフォームを開けます。

フォームの欄は次の四つです。

| 欄 | 日本語ラベル | 初期値 |
| --- | --- | --- |
| 名前 | スポット名 | 空 |
| 場所 | エリア | 空 |
| 分類 | カテゴリー | 公園 |
| メモ | ひとこと | 空 |

位置は地図クリックで入ります。送信は **この場所を残す**、中止は **閉じる** です。成功すると「スポットを残しました。」と出ます。失敗すると英語の "Could not save." が出ます（この一文だけ日英が分かれている点は既知です）。

ゲストの登録は公開一覧に出ます。`ownerUserId` は空のままです。あとから `/my` で直すことはできません。後から直したい人は、残す前に **ログイン** してください。サーバは作成時に `ctx.user.id` があれば所有者として刻み、なければ `null` のまま公開します。[2]

## つなぐ

ページ下部はプロダクトの三語を繰り返すだけです。見つける人は地図と一覧を使い、残す人は短いメモを書き、それが次の誰かのヒントになります。フッターは次の一文です。

> Spot は、身近な発見を静かに共有するためのオープンな場所です。

年号は `2026 / open to all` です。Coral のマーケティングバッジや、人数を盛った指標カードはありません。

## 自分の分だけ直す

ヘッダーの **マイスポット** はログイン後に出ます。アドレスは `/my` です。未ログインで開くと Manus のサインイン（「Sign in to Spot」）へ送られます。Google / Microsoft / Apple / メール / パスキーが使えます。

ログイン後の `/my` はダッシュボードではなくリストです。見出しは **自分が残した場所** です。説明は次のとおりです。

> 後からメモを直したり、もう公開したくない場所を消したりできます。編集と削除は、自分が登録したスポットにだけ出ます。

一件も無いときは「まだスポットを登録していません。」とだけ出し、**地図帳をひらく** でアトラスへ戻します。偽の行は置きません。自分の行には名前、エリア、カテゴリー、ひとことのあとに **編集**（アウトライン）と **削除**（コーラルの文字、確認ダイアログ）があります。削除確認は「このスポットを削除しますか？」で、公開一覧からも消えること、取り消しできないことを述べます。公開一覧側に、他人の行へコーラルの編集ボタンは増えません。[2] [3]

## 公開データの取り方

`curl` 無印は Cloudflare 1010 で拒まれることがあります。ブラウザ相当の User-Agent を付けます。

```bash
python3 fetch_trpc.py https://spotatlas-jettiem7.manus.space/api/trpc/spots.list
```

この一式の `data/spots.list.json` は、2026-09-22 に同じ方法で保存した公開レスポンスです。件数や文言を案内に書くときは、この JSON か、その時点の公開 API を正とします。想像のサンプル地点は足しません。[1]

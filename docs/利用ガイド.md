# Spot_Info V01R01 — 利用ガイド

[公開サイト](https://spot-info.web.app/)の地図とスポット一覧はログインせずに閲覧できます。地域やカテゴリーで絞り込み、一覧または地図のマーカーからスポットを確認します。

## Googleでログインして投稿する

「ログイン」または投稿ボタンからGoogleログインを開始します。別ウィンドウが開くため、ブラウザでポップアップを許可してください。管理者を含め、GitHubログインは不要です。Googleのメールアドレス確認が済んだアカウントを使用します。

ログイン後、地図上の位置を選び、スポット名、エリア、分類、メモを入力して保存します。投稿内容と座標は一般公開されます。個人の住所や非公開の情報を投稿しないでください。

## 自分の投稿を管理する

[マイスポット](https://spot-info.web.app/my)では、自分がこのFirebase版で投稿したスポットを編集・削除できます。他の利用者の投稿を編集する権限はありません。位置と投稿日時は編集できません。

旧版から移した4件は、元の投稿者との対応が確定していないため、公開閲覧のみの状態です。初回ログインした利用者やオーナーへ自動的に所有権を与えていません。所有者を対応付ける場合は、別途本人確認と管理操作が必要です。

## オーナー・管理者

[管理者入口](https://spot-info.web.app/admin)もGoogle専用です。初期オーナーは `hiro.mochian@gmail.com` です。通常のGoogleログインだけでは管理者になりません。管理権限はサーバー側で付与したカスタムクレームで判断します。

管理画面では公開スポット数と未割当の旧データ数を確認できます。管理者という理由だけで他人の投稿を変更できる設計ではありません。

## ログインできない場合

ポップアップを許可して再試行してください。共有端末では利用後にログアウトしてください。サイト管理者はFirebaseのGoogleプロバイダー、承認済みドメイン、Google Auth Platformの対象設定を確認します。新プロジェクトは「本番環境・外部」となっており、テストユーザー限定ではありません。

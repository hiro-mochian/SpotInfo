# Spot_Info プライバシーポリシー

最終更新：2026年9月23日。運営者：hiro-mochian。お問い合わせ窓口：**hiro.mochian@gmail.com**。

## 取得する情報と利用目的

Spot_Infoは、身近なスポットを地図で共有するサービスです。公開スポットの閲覧にログインは必要ありません。登録・投稿・自分の投稿の編集と削除にはGoogle認証を使用します。管理者の本人確認にはGitHub認証を使用します。

Google認証では、Googleの利用者識別子、メールアドレス、表示名、プロフィール画像など、Googleが提供する基本プロフィールを取得します。GitHub認証では、GitHubの数値ID、ユーザー名、メールアドレスなどの基本プロフィールを取得します。これらは本人確認、ログインの維持、投稿の所有者確認、不正な操作の防止に使用します。Gmail本文、Google Driveのファイル、連絡先、GitHubリポジトリの内容は取得しません。

利用者が入力するスポット名、エリア、分類、メモ、位置情報、投稿日時を保存します。サービスの安全な提供のため、認証状態やアクセスに関する技術情報を基盤サービスが処理する場合があります。

## 公開される情報

スポットの投稿内容と位置情報は一般公開されます。公開APIからアカウントのメールアドレスや所有者の内部IDは返しません。ただし、投稿本文に書いた個人情報はそのまま公開されるため、自宅の位置、個人の連絡先、他人の非公開情報などを入力しないでください。

## 利用する外部サービス

サイトの配信にはGitHub Pages、認証セッションとデータ保存にはSupabaseを使用します。GoogleとGitHubはそれぞれの認証を処理します。各提供者の設備でデータが取り扱われ、国外の設備が使われる場合もあります。

地図はOpenStreetMapのタイルを取得します。地名検索を実行すると、入力した検索語がPhotonへ送信されます。フォントの表示にはGoogle Fontsを使用します。これらの通信先には、通常の通信情報としてIPアドレスやブラウザに関する情報が伝わる場合があります。

本サイトには、取得したGoogle利用者データを広告目的で販売する処理や、生成AIの学習に利用する処理を設けません。サイトの実行にManusの認証、API、ホスティングは使用しません。

## ブラウザ保存と安全管理

ログインを維持するため、認証SDKはブラウザの保存領域を使用します。認証先やログイン後の戻り先も一時的に保存します。共有端末では利用後にログアウトしてください。

認証元検証APIは、GoogleまたはGitHubにトークンを提示して本人を確認します。このAPIはプロバイダーのトークンをDBやアプリケーションログへ保存しません。セッションと認証元の一致を確認してから権限を付与し、Googleセッションで管理権限を使えないよう分離します。

通信にはHTTPSを使用します。権限確認と所有者の照合を行いますが、インターネット上のすべての危険を完全に排除できると保証するものではありません。

## 保管と削除

アカウントと投稿の情報は、サービスの提供と安全な運用に必要な間、保存します。保存期間を一律の日数で自動削除する機能は設けていません。公開投稿は、自分の投稿一覧から本人が削除できます。

退会やアカウント情報の削除は、上記の窓口へご連絡ください。運営者が本人確認のうえ対応します。バックアップや基盤サービスのログからの消去は、各サービスの保持期間・仕組みに従う場合があります。公開済みの投稿が第三者に保存された場合、その複製まで削除できるとは限りません。

GoogleまたはGitHub側でアプリへのアクセス許可を取り消すこともできます。ただし、許可の取消しだけでは本サービスに保存されたアカウントや投稿は削除されません。

## 変更について

情報の利用方法を変更する場合は、本ページなど分かりやすい場所で告知します。Google利用者データの新しい利用目的や追加の取得範囲が生じる場合には、必要な説明と同意を得てから変更します。

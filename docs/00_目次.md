# Spot ドキュメント一式

このフォルダは、公開サイト [Spot](https://spotatlas-jettiem7.manus.space/#atlas) の改定後に渡すドキュメント一式です。読み順は次のとおりです。

1. [README.md](README.md) — 公開所在といまの事実
2. [利用ガイド.md](利用ガイド.md) — 見つける / 残す / つなぐ / マイスポット
3. [変更履歴.md](変更履歴.md) — 残したものと切ったもの
4. [設計監査.md](設計監査.md) — Design Read と五軸
5. [公開URL.md](公開URL.md) — 四つの URL の記入欄
6. [data/spots.list.json](data/spots.list.json) — 公開 API スナップショット
7. [screenshots/](screenshots/) — ヒーローと地図帳の画面
8. [ソースについて.md](ソースについて.md) — ソースの由来
9. [source/](../source/) — 復元したアプリケーションソース

ソースは公開バンドルから復元してあります。git checkpoint と Google サイト URL は未記録です。判明したら `公開URL.md` と README の表へ追記してください。

# ソースコードについて

この配布物は現在公開したFirebase版を再ビルドできる全ソースを含みます。`client/` が現在の画面とFirebase接続のコードです。`firebase.json` と `.firebaserc` が配置先、`firestore.rules` と `firestore.indexes.json` がDBの権限制御を定義します。

`npm ci` の後に `node scripts/setup-public-config.mjs` を実行すると、同梱の公開設定から `.env.local` を作成できます。公開設定は認証トークンや管理用の秘密鍵ではありません。Git管理の対象外である秘密値はZIPにも含めません。

`source/` は最初に提供された復元ソース、`supabase/` は旧データベースの移行履歴です。Firebase版はこれらを起動時に読み込みません。旧資料は `docs/history/pre-firebase/` にまとめています。

`scripts/import-firebase.mjs` は移行時に使用した管理用スクリプトです。既存データの上書きを防ぐため、移行済み環境への再実行は失敗する設計です。通常の運用や再デプロイ時には実行しないでください。

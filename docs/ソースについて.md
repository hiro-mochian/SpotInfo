# ソースについて

著者：**Manus AI**。更新：2026-09-23。

今回のZIPには現時点の実行可能な移植版ソースを含みます。画面は `client/`、DBは `supabase/`、公開前検査とPages補完は `scripts/`、依存関係はルートの `package.json` と `package-lock.json` にあります。起動には `.env.example` を参考に公開用のSupabase接続設定が必要です。認証用の秘密キーは含みません。

`source/` は、添付ZIPにあった元サイトの本番バンドル由来の復元ソースです。元の完全なWebDevプロジェクトではありません。履歴を残すため別に保持しており、移植版の実行ディレクトリとは区別しています。

元の画面・コピー・配色を再利用し、不足していた起動処理やUI部品、Supabase RPC、所有者制御、ビルドとテストを補完しました。移行後のDBでは旧所有者IDを保存していますが、新しいアカウントへの対応付けは未実施です。

GitHubの `checkpoint-2026-09-23-supabase-build` タグがこの移植版の保存点です。提供するGit bundleには履歴とタグも含みます。Manus WebDevの正式checkpointではありません。

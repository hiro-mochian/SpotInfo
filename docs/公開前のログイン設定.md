# 公開前のGoogle・GitHubログイン設定

2026-09-23更新。一般利用者とスポット登録者は**Googleのみ**、オーナー・管理者は**許可済みGitHubのみ**です。コード・投稿DB・認証元検証APIは実装しましたが、Google/GitHubのサイト用OAuthアプリはまだ設定されていないため、サイトは公開していません。

設定する秘密キーはSupabaseの画面へ直接入力します。チャット、ソース、GitHub Actionsの公開変数、スクリーンショットには載せないでください。開発作業用CLIのGitHub/Supabase認証とは別の設定です。

## 1. 一般利用者用Google OAuth

[Google Cloud Console](https://console.cloud.google.com/auth/overview)で、ご自身が管理するプロジェクトを選択するか、SpotInfo用プロジェクトを作成します。Google Auth PlatformのBranding、Audience、Data Access、Clientsを設定します。Google以外のサービスへ移行する必要はありません。[1]

| 項目 | 設定値・注意点 |
| --- | --- |
| アプリ名 | `SpotInfo` |
| Audience | 一般のGoogleアカウントを受け入れるならExternal |
| 開発中のテスト | Testingの場合は、ご自身など必要なGoogleアカウントをTest usersへ追加 |
| Data Access / scopes | `openid`、メールアドレス、基本プロフィールのみ。Drive/Gmail等を追加しない |
| OAuth Clientの種類 | Web application |
| Authorized JavaScript origins | `https://hiro-mochian.github.io`（`/SpotInfo/`を付けない） |
| Authorized redirect URIs | `https://xscvnppiknkzxelzgfnj.supabase.co/auth/v1/callback` |

Client IDとClient secretが発行されたら、[Supabaseの認証プロバイダー設定](https://supabase.com/dashboard/project/xscvnppiknkzxelzgfnj/auth/providers)でGoogleを有効にし、両方を入力して保存します。一般公開時にはAudienceの公開状態・Googleが要求する審査やブランド確認の条件も確認してください。Testingのまま全Google利用者が登録できるとは扱いません。

## 2. オーナー・管理者用GitHub OAuth

[GitHubのOAuthアプリ登録](https://github.com/settings/applications/new)を開き、次の値を設定します。[2]

| 項目 | 設定値 |
| --- | --- |
| Application name | `SpotInfo Admin` |
| Homepage URL | `https://hiro-mochian.github.io/SpotInfo/` |
| Application description | `SpotInfo owner and administrator sign-in` |
| Authorization callback URL | `https://xscvnppiknkzxelzgfnj.supabase.co/auth/v1/callback` |
| Enable Device Flow | チェックしない |

Client IDを控え、Generate a new client secretで秘密キーを発行します。Supabaseの同じプロバイダー設定画面でGitHubを有効にし、Client IDとClient secretを入力して保存します。求める権限はプロフィールとメール情報の読み取りのみで、サイトからGitHubリポジトリを操作する権限は要求しません。

## 3. その他の認証を無効にする

SupabaseのSign In / Providersで、Emailを無効にし、Phone・Anonymousや他の外部認証も無効であることを確認します。これはメールの確認手順を省略する設定ではなく、メール/パスワード方式自体を提供しない設定です。既存のアプリ利用者がいないことは変更前に確認済みです。

Site URLと許可する戻り先は `https://hiro-mochian.github.io/SpotInfo/` に設定済みです。OAuth client secretやサービス管理キーはクライアントへ渡しません。

## 4. 初期オーナーを承認する

初期オーナー候補は **GitHub `hiro-mochian`、数値ユーザーID `53967801`** です。このアカウントへの権限付与を確認してから、サーバーの非公開名簿へownerとして追加します。現時点では追加していません。その他の管理者も自動登録しません。

管理者入口は公開後の `/SpotInfo/admin/` です。現在の管理画面は認証と件数・所有者対応状況の確認用であり、ユーザーの削除、自己昇格、他人の投稿の編集・削除は行えません。

## 5. 公開と実動作確認

設定後に `node --env-file=.env.local scripts/check-deployment.mjs` を実行します。GoogleとGitHubの有効化、他方式の無効化、オーナー名簿、未認証APIの拒否が確認できない場合は公開を止めます。

正式URLの公開後、Googleでの利用者登録・投稿・本人編集削除とログアウト、GitHubでの許可済み管理者ログイン、未許可GitHubの拒否、Googleセッションでの管理画面拒否を実際に確認します。同じメールの両プロバイダーを利用する場合も権限が混ざらないことを確認します。設定値の存在だけでログイン往復が検証済みとはしません。

旧投稿1件の所有者は、本人がGoogleでログインした後に本人確認のうえ対応付けます。オーナー権限を付けただけで他人の投稿を自分の投稿にしません。

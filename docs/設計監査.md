# Spot 設計監査

著者: **Manus AI**  
監査対象: [https://spotatlas-jettiem7.manus.space/#atlas](https://spotatlas-jettiem7.manus.space/#atlas)  
監査日時: 2026-09-22

トークンを選ぶ前に、面を一文で固定します。Spot の面は「東京の紙の地図帳を開いたところに、短い手書きのメモが載っている」です。SaaS のデバイスモックや、信頼を盛るダッシュボードではありません。[1]

## Design Read

| 項目 | 内容 |
| --- | --- |
| Face | ノートが、開いた東京の紙のアトラスの上に載っている |
| Density | 編集的。ダッシュボードではない |
| Motion | ほぼ無し。マーカーのフォーカス以外は動かさない |
| Radius | 2px か無し。ピルを全面に使わない |
| Type | 見出しは日本語明朝、本文は日本語ゴシック |
| Accent | コーラル一つ。登録とピン（および検索送信）に限る |

色を決める前に答える四つは、公開面で次のとおりです。地図はキャンバスであり、マーケティングページの中のウィジェットではありません。今日の正直な数字は **公開 3件** です。プロダクトの三語は **見つける / 残す / つなぐ** です。紙 `#f3eee4`、インクの暗い紺、コーラル `#de6848` は残します。[1] [2]

## 五軸

公開面は、旧 `Spot_info` ランディングを直したあとの状態です。コピーだけでなく、地図の置き方と件数の出し方まで紙のアトラスに寄せています。

| 軸 | /10 | 一行 |
| --- | --- | --- |
| Philosophy | 8 | メタファーがコピーだけでなく、地図フレームと紙色に出ている |
| Hierarchy | 8 | 見出しが勝ち、指標カードと二重 CTA が消えている |
| Craft | 7 | JP フォントはロード済み。ズームコントロールは残る。ピンはコーラル |
| Function | 8 | 検索、一覧、残す、所有者の編集/削除の経路が残っている |
| Originality | 8 | テンプレート SaaS ではなく、件数 3 の紙のアトラス |

総合は **7.8 / 10** です。残すのは紙、インク、コーラル、三語、見出し、オープンに残せる姿勢です。まだ削れるのは、ズーム UI の存在感と、ホスト付与の "Made with Manus" バッジが視線を奪う点です。[1] [3]

## 残す / 直す

残したもの:

- 紙の地面 `#f3eee4` / カード `#fbf7ee`
- インク `#1c2430` 前後
- コーラル `#de6848` を登録とピンに限る
- 見出し「ここ、いいよ」
- 三語ナビ
- 残すのにログインは不要。直すのに所有者は必要

直したもの:

- 偽の指標
- 地図の上に載るガラスのデバイス
- Street View / 地図種別 / 全画面
- 何でもピル、分類が全部「その他」
- 日本語アトラスなのに `lang="en"`
- ブランド分裂

日本語見出しの行間は 1.2 以上です。`/my` の h1 は `leading-[1.2]` です。本文は IBM Plex Sans JP、見出しは Shippori Mincho で、CJK を DM Sans だけに任せていません。[2] [3]

## 公開面で確認した操作の残存

見つけるは、地名検索と一覧フィルタとピン選択で動きます。残すは、地図クリックで緯度経度が入り、ゲストでも `spots.create` できます。つなぐは下部の三語説明です。所有者は `/my` で `spots.mine` を読み、`update` / `delete` します。公開リストに他人向けのコーラル操作は増えていません。

東京判定はクライアント側です。緯度 35.5–35.9、経度 139.4–140 の内側を「範囲内」とし、ヒーローカードは最大 3 件、一覧は範囲内を先にします。画角外は消さず、**地図の外** と書きます。[1]
